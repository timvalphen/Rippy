# Rippy

Video’s downloaden, audio opslaan en lokale video’s comprimeren op je Mac.

## Download

[Rippy 1.17 voor Mac (Apple Silicon, macOS 14 of nieuwer)](https://github.com/timvalphen/Rippy/releases/download/V1.17/Rippy-1.17-34.zip)

[Release notes en eerdere versies](https://github.com/timvalphen/Rippy/releases)

Deze versie is niet door Apple genotariseerd. macOS kan bij de eerste keer openen een waarschuwing tonen.

## Updates

Rippy 1.17 gebruikt de updategegevens in version.json. Nieuwe versies kunnen vanuit de app worden gedownload, gecontroleerd en geïnstalleerd. Actieve taken worden niet onderbroken.

Wie een oudere Rippy-versie gebruikt, moet mogelijk één keer de nieuwe app handmatig installeren. Het oude website-updateadres blijft voorlopig ongewijzigd.

De normale app en lokale testapp blijven gescheiden. Ripmas en testversies worden niet via deze productiefeed aangeboden.
